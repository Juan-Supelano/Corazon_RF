# Datos originales

`heart.csv`: [Heart Failure Prediction Dataset](https://www.kaggle.com/datasets/fedesoriano/heart-failure-prediction) (fedesoriano, Kaggle).
918 registros, 11 variables y la variable objetivo `HeartDisease`. Combina cinco bases de datos de enfermedad cardiaca
(Cleveland, Hungarian, Switzerland, Long Beach VA y Statlog) del UCI Machine Learning Repository.

En el archivo original los datos faltantes de `Cholesterol` (172) y `RestingBP` (1) venían como `0`.
En esta copia ya están como celdas vacías.
